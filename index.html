Chrome extensions

Three extensions published on the Chrome Web Store. Each keeps its data in your browser, with no account and no server of mine.

Theme Studio for GitHub

A theme engine for github.com and gist.github.com: 31 handcrafted themes, animated backgrounds and short cinematic effects with sound.

  • Restyles the whole site, including code, diffs, issues, pull requests, Actions, settings and gists, while keeping contrast readable.
  • Starring, forking, opening a pull request or merging plays a themed effect with particles, a title card and a sound. Sixteen kinds of action can each be switched on or off and previewed.
  • Build your own theme from six colors, a particle style, a background scene, a sound pack and a corner style.
  • Every sound is synthesized live in the browser, so the extension ships no audio files. It respects the system reduce-motion setting.
  • Runs only on github.com and gist.github.com. No analytics, no remote code and no remote fonts.
  • JavaScript
  • CSS
  • Manifest V3
  • chrome.storage
  • Web Audio API

Theme Studio for Claude

57 themes, animated scenes and sound for claude.ai, with effects that react as you chat.

  • Four theme families: Classics, Cinematic, Light, and Heroes & Worlds. Star favorites to pin them to the top, or build a custom theme from accent color, corner style, font and glow.
  • Eleven animated background scenes, matched to each theme.
  • Effects for ten moments of a chat: sending, thinking, a finished reply, stopping, a new chat, artifacts, ratings, retries, attachments and copying. Each one can be switched off.
  • Four sound packs, or sounds matched to each theme, all generated with the Web Audio API. The popup previews every effect and sound.
  • Works only on claude.ai. It does not store or send conversations, and it makes no network requests of its own.

Task Board — Scheduled Reminders

A personal dashboard in Chrome's side panel: scheduled tasks with reminders, time spent per website and live weather.

  • Schedule tasks with a due date and time, and get a Chrome notification the moment they are due.
  • See screen time by website for today, this month or this year. It reads only the hostname of the active tab, never the full address or page content, and the data can be exported or reset.
  • Current weather for your location sits in the header and is cached for 30 minutes to limit requests.
  • Six themes, with a custom accent color, border radius and font.
  • No account, no server and no cloud sync. Everything lives in chrome.storage.local and is removed when you uninstall.
